# 秒切

[English](./README.en.md)

**Trae CN 本地多账号会话管理 — 开源、纯本地、手动切换**

秒切帮助你管理多个 Trae CN（中国版）账号，在 Windows 上一键切换 IDE 登录会话，告别反复登录。

> ⚠️ **本项目仅支持 Trae 中国版（Trae CN）**，不支持 Trae 国际版。

---

## 这是什么

秒切是一款 **Electron 桌面应用**，只做一件事：在你**本人名下、合规注册**的多个 Trae CN 账号之间，**手动**切换 IDE 会话。

| 特性 | 秒切 | 常见方案 |
|------|------|----------|
| 🔒 数据存储 | ✅ 100% 本地，无远程服务器 | ⚠️ 部分含云端或不可审计 |
| 🔄 切换方式 | ✅ 仅手动，由你决定 | ⚠️ 部分支持自动轮换 |
| 📖 代码 | ✅ MIT 开源，可自行审查 | ❌ 多为闭源 |
| 🔍 路径检测 | ✅ 自动扫描注册表/开始菜单/磁盘 | ❌ 需手动指定 |
| 🌐 登录方式 | ✅ 浏览器登录（支持 2FA）、Token、IDE 导入 | ⚠️ 通常仅 Token |

> 🚫 **不是额度套利工具。** 不提供自动换号、不代理 API、不上传凭证。

---

## 功能一览

| 模块 | 说明 |
|------|------|
| 👤 账号管理 | 浏览器登录 / 粘贴 Token / 从 IDE 导入；支持搜索、排序、备注 |
| 🔄 会话切换 | 一键写入会话并重启 Trae CN；系统托盘快捷切换 |
| 🔑 登录续期 | 浏览器续登、Cookie 方式刷新 Token |
| 💾 数据备份 | JSON 导出，支持 AES-256-GCM 密码加密；定时自动备份 |
| 🔍 智能扫描 | 启动时自动扫描注册表、开始菜单、多磁盘查找 Trae CN 安装位置 |
| 🎨 界面 | 深色 / 浅色主题，中文 / English；无边框窗口 + 圆角设计 |
| ⚙️ 高级 | 环境清理、设备标识管理 — 仅在会话异常时使用 |

## 安装

### 从源码运行

```bash
git clone https://gitee.com/yunqingsir/miaoqie.git
cd miaoqie
npm install
npm start
```

### 构建安装包

```bash
npm run dist:win    # 构建 Windows x64 安装包 → release/
```

构建产物：
- `release/秒切-{version}-win-x64.exe` — NSIS 安装程序
- `release/秒切-{version}-win-x64.zip` — 绿色便携版

## 快速上手

```
启动 → 同意免责声明 → 配置 Trae CN 路径 → 添加账号 → 点击切换
```

**配置路径**：首次启动时，秒切会自动扫描系统中的 Trae CN 安装位置（注册表 → 开始菜单 → 常见路径 → 多磁盘扫描）。如果自动扫描未找到，可手动选择 `Trae CN.exe`。

**添加账号** — 三选一：

| 方式 | 说明 |
|------|------|
| 🌐 浏览器登录（推荐） | 弹出窗口登录 `www.trae.cn`，支持 2FA，成功后自动添加 |
| 📋 粘贴 Token | 从 IDE 的 F12 → Network → `GetUserToken` 接口获取 |
| 📥 从 IDE 导入 | 在 Trae CN 中登录目标账号后，一键导入当前会话 |

**切换账号**：在账号页点击「切换」，Trae CN 会关闭并以目标账号重新打开。切换前请保存 IDE 中未保存的工作。

**切换模式**：

| 按钮 | 说明 |
|------|------|
| 🔄 切换 | 日常使用：写入目标会话并重启 Trae CN |
| ⚡ 重置环境后切换 | 先清理本地缓存与设备标识再切换，仅在会话异常时使用 |

**备份与迁移**：在账号页导出 JSON（可设密码加密），需要时通过导入功能恢复。

## 数据路径

| 内容 | 路径 |
|------|------|
| 秒切配置与账号库 | `%APPDATA%/miaoqie-data/` |
| Trae CN 数据目录 | `%USERPROFILE%/.trae-cn/` |
| Trae CN AppData | `%APPDATA%/Trae CN/` |

## 常见问题

| 问题 | 解答 |
|------|------|
| 切换后 Trae CN 没打开？ | 检查设置中的路径是否正确，确保 `Trae CN.exe` 可执行 |
| Token 无效？ | 检查是否过期，推荐用浏览器登录方式重新获取 |
| 切换后仍显示旧账号？ | 手动关闭 Trae CN，尝试「重置环境后切换」 |
| 支持 macOS 吗？ | Trae CN 目前仅提供 Windows 版，秒切跟随支持 Windows |
